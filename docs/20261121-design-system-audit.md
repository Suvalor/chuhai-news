# 结论

作者板块之所以大，是因为首页把**全部作者**都铺成了 158px 高的格子，作者数量不设上限，其中还包括 0 篇的作者。改法是复用搜索页已有的作者胶囊组件 `.s-au`，只列有文章的作者。这样首页作者板块的高度预计从约 1,265px 降到 300px 左右（估算），不用新增组件。

# 线上实测（2026-11-21，视口 1512px）

| 首页区块 | 高度 |
|---|---|
| 刊头 | 507px |
| 01 按问题找 | 852px |
| 02 今日必读 | 455px |
| **03 作者** | **1,265px**（5 列 × 7 行，每格 249×158px） |
| 04 榜单 | 3,735px |

- 共 32 个作者格子：**9 位是 0 篇**，23 位各 1 篇。
- 刊头的「32 位作者」把 0 篇的也算进去了，但站点地图只收有文章的作者（`main.py:398`），口径不一致。
- 手机端是 2 列，32 格约 16 行，估算 2,400px 以上，相当于近 3 屏。这个数是按 CSS 推算的，浏览器窗口缩不到手机宽度，没有实测。
- 「跟着人读，比跟着话题读更快」这句提示，目前站不住：每位作者都只有 1 篇，读者点进作者页只能看到同一篇文章。

# 修改建议（按优先级）

## 1. 只列有文章的作者（必须，改动 1 行）

`db.authors()` 已经算好了每位作者的篇数 `n`。首页和刊头计数改为只取 `n > 0` 的作者，0 篇作者不再链接到空页面。

## 2. 首页作者改用现有的胶囊组件 `.s-au`（推荐）

搜索页已有一套作者胶囊：`.s-authors` / `.s-au`，32px 小头像 + 名字 + 篇数，圆角描边，悬停反色。首页改用同一个组件：

- 桌面端自动换行。23 位约 4 行 × 64px，板块高度约 300px（估算）。
- 手机端改成一行横向滑动（`flex-wrap: nowrap; overflow-x: auto`），板块只占一行高度。
- 排序沿用现在的「篇数多的在前，同篇数按名字」。
- 好处：少一套作者卡片样式（`.au-grid`、`.au-cell`、`.au-n` 可以删掉），首页和搜索页的作者长得一样，符合「一致优先」。

## 3. 设上限，等作者多了再用（可选，现在不做）

有效作者超过 24 位时，首页只显示前 24 位，末尾放「全部 N 位作者 →」，链接到搜索页。现在 23 位，还用不上。

## 4. 提示语与数据对齐（可选）

在出现「2 篇以上的作者」之前，可以考虑：
- 把提示改得朴素些，例如「本站收录的作者」；
- 或者把作者板块挪到榜单后面，让文章先出现。

这一项是编辑判断，由你决定。

# 设计系统审计（其余部分）

## 概况

只审了站点前台的 `site.css`（306 行）和首页模板，没审后台和 Excel 工具页。

**粗评 72 / 100**：颜色令牌管得好；字号和间距没有刻度，靠逐处写死的 px 维持；首页作者板块的组件选错了。

## 令牌覆盖

| 类别 | 已定义令牌 | 写死的值 |
|---|---|---|
| 颜色 | 9 个（paper / ink / red / mute / mute2 / faint / line / hover / track） | 1 处十六进制 `#e3ddd2`（`.heat`），4 处 rgba 是纸色和墨色的半透明版 |
| 字体 | 6 个字族令牌 | 无 |
| 字号 | 没有刻度令牌 | 16 种 px 值（10–40px），外加十几个 `clamp()` |
| 间距 | 只有 `--pad`、`--head` | 区块底部留白就有 96 / 112 / 120 / 128px 四种 |
| 动效 | `--ease` 1 个 | 时长 .2s / .22s / .28s / .32s / .5s 混用 |

## 组件一致性

| 组件 | 问题 | 建议 |
|---|---|---|
| 作者展示 | 首页 `.au-cell` 方格、搜索页 `.s-au` 胶囊，两套样式做同一件事 | 统一用 `.s-au`（见建议 2） |
| 头像 `.avatar` | 4 个尺寸：32 / 36 / 44 / 52px，另有 40px | 收成 sm / md / lg 三档 |
| 区块标题 `.sec-hd` | 各区块统一，做得好 | 保持 |
| 目录行 `.idx` | 类目和专题共用，做得好 | 保持 |

## 优先事项

1. 首页作者板块：做建议 1 + 2。这是唯一影响阅读体验的问题，改动小。
2. `#e3ddd2` 和 4 处 rgba 收进颜色令牌，改动小、零风险。
3. 字号和间距刻度：等下次改版再做，现在不值得单独动。

# 实施记录（2026-11-21）

建议 1、2 已改：`main.py` 首页只取 n>0 的作者；`index.html` 作者板块改用 `.s-authors` / `.s-au`；`site.css` 删掉 `.au-grid` / `.au-cell` / `.au-n`，新增 `.home-au`（手机端一行横滑）。本地预览按 23 位作者模拟实测：1512px 宽板块 432px（原线上 1,265px），375px 宽 207px 且页面无横向溢出。未部署。
